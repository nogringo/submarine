# Submarine 浏览器扩展隐私政策

最后更新：2026年10月18日。

Submarine 是一款密码管理器。它的浏览器扩展会显示您密码库中的密码、支付卡和笔记，让您创建和编辑它们，帮您复制，将您的登录信息填充到网站中，并显示发送到您为登录信息添加的邮箱地址的邮件。本政策说明扩展如何处理您的数据。简而言之：不存在 Submarine 服务器，扩展也不会向其开发者发送任何内容。

## 留在浏览器中的内容

- 您创建或打开的每个密码库的密钥，以及您为它设置的名称和颜色。它们由此浏览器的一个密钥加密，而设置锁定密码后，这个密钥本身也受锁定密码保护。
- 密码库内容的副本，以便无需等待网络即可打开密码库。副本同样经过加密。
- 邮箱地址收到的消息，按收到时的原样保存：以该地址的密钥加密。扩展每次显示它们时才解密，绝不存储解密后的内容。
- 您的设置：自动锁定时间、剪贴板清除时间、密码生成器的选项，以及新邮箱地址使用的邮件桥接、中继和服务器。
- 您未保存就离开的表单，以便重新打开扩展时再次显示。它只保存在浏览器的内存中，绝不写入磁盘，并会在您保存、放弃、锁定扩展或关闭浏览器后消失。

从扩展中移除密码库，会从浏览器中删除它的密钥和副本。卸载扩展会删除它存储的所有内容。

## 离开浏览器的内容

您的密码库存放在 Nostr 中继上：这些服务器由独立的运营者运行，为任何人存储数据。您的项目在到达中继之前就已在您的设备上加密，因此中继只保存它们无法读取的数据。

为了下载您的密码库，扩展会连接到它们的中继：即每个密码库列出的中继（若没有则使用 Submarine 的[默认中继](https://github.com/nogringo/submarine/blob/main/packages/nostr_passwords/lib/src/defaults.dart)），以及发布密码库中继列表的三个目录中继。与您访问的任何网站一样，每个中继都能看到您的 IP 地址，还能看到您打开的每个密码库的公钥，扩展用这个公钥登录中继并请求该密码库的数据。

当您创建、编辑、收藏、移至回收站或恢复项目时，扩展会在您的设备上加密项目的新版本，并将其发送到所在密码库的中继。当您永久删除项目时，扩展会请求这些中继删除它的每个版本。尚未被任何中继接受的更改会留在浏览器的加密副本中等待，并在您下次打开扩展或点击同步按钮时重新发送。

密码生成器在您的浏览器中运行：它生成的内容只有放进您保存的项目中，才会离开浏览器。

当您导入 Bitwarden 导出文件时，扩展会在您的浏览器中读取您选择的文件，然后将其中的项目作为您新建的项目，保存到您选择的密码库中。当您导出密码库时，扩展会将文件保存到您的电脑上，并用您选择的密码加密；如果您关闭密码保护，则不加密。该文件不会发送到其他任何地方。

当您通过扩展窗口或键盘快捷键要求填充登录信息时，扩展会将用户名和密码写入当前页面的登录表单，且仅在页面地址与该登录匹配时才会这样做。和您手动输入时一样，网站会在您登录时收到它们。

## 邮箱地址

登录信息可以通过添加字段的菜单获得自己的邮箱地址，例如 `npub1...@uid.ovh`。扩展会为每个地址创建一个与您的密码库无关的新密钥，并将其保存在该登录信息的隐藏型字段中，与项目的其余内容一起加密。域名属于一个邮件桥接，除非您在设置中选择了其他桥接，否则就是 `uid.ovh`：这是一台由独立的运营者运行的服务器，它像任何邮件服务器一样接收发送到该地址的邮件，用该地址的密钥加密这些邮件，再将其转交给该地址的中继。扩展从不发送邮件，也从不连接到桥接。

当您保存带有新邮箱地址的登录信息时，扩展会发布三份用该地址的密钥签名的公开列表，以便桥接知道该把邮件投递到哪里：该地址的中继列表，发送到这些中继和三个目录中继；其邮件送达的中继列表；以及接收对中继而言过大的邮件的服务器列表。这些列表写明的是该地址的密钥及其中继和服务器，从不涉及您的密码库。默认情况下，它们是 Submarine 的[默认邮件中继和服务器](https://github.com/nogringo/submarine/blob/main/packages/nostr_passwords/lib/src/defaults.dart)；您可以在设置中更改新地址使用的中继和服务器。

在显示带有邮箱地址的登录信息期间，扩展会连接到该地址的中继（在目录中继上找到），用该地址的密钥登录这些中继，下载其最新消息，并持续接收新消息，直到您关闭该登录信息。每个中继都能看到您的 IP 地址和该地址的公钥。扩展还会接收发送到该公钥的私信（NIP-17）。对中继而言过大的邮件，会在您打开时以加密形式下载，来源是该地址或桥接的某台服务器，若没有则是 Submarine 的默认服务器；该服务器能看到您的 IP 地址。

当您保存邮件时，扩展会将整封邮件（包括附件）写入您电脑上的一个文件。当您删除消息时，扩展会请求该地址的中继删除它。永久删除登录信息不会从中继中删除它的消息。消息中的链接只有在扩展向您显示它指向哪里、并经您确认后，才会在新标签页中打开。

## 扩展不会做的事

- 它没有账户，也没有自己的服务器：开发者不会从它那里收到任何数据。
- 它从不发送邮件，也从不显示邮件会从网络加载的图片或其他内容：它以纯文本显示邮件。
- 它没有数据分析，没有跟踪，也没有广告。
- 它不会读取您访问的页面的任何内容，唯一的例外是您要求填充登录信息时，它会读取当前页面的字段，以找到用户名和密码应填入的位置。在您打开扩展时，它会读取当前标签页的地址，以便优先显示该网站的登录信息。这两者都不会离开您的浏览器。
- 它只会把您复制的内容以及它所填充登录的验证码写入剪贴板，并在设置中选择的时间过后清空剪贴板。它从不读取剪贴板。

## 权限

- 存储：如上所述，将您的密码库和设置保存在浏览器中。
- 写入剪贴板：在您要求时复制密码、验证码或其他任何字段。
- 定时器：在自动锁定时间过后锁定密码库。
- 活动标签页：扩展只能访问您在其上打开扩展或使用快捷键的那个标签页，用它的地址优先显示该网站的登录信息，并在您要求时向它的页面填充登录信息。
- 脚本：在您要求时，将登录信息填充到该标签页的页面中。
- 离屏文档（仅限 Chrome）：复制所填充登录的验证码，并在剪贴板清除时间过后清空剪贴板，即使扩展窗口已关闭也是如此。
