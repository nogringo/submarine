# Submarine ブラウザ拡張機能のプライバシーポリシー

最終更新日：2026年10月18日

Submarine はパスワードマネージャーです。そのブラウザ拡張機能は、保管庫にあるパスワード、カード、メモを表示し、それらの作成や編集、コピーを行い、ウェブサイトにログインを入力し、ログインに付けたメールアドレス宛てに送られたメールを表示します。このポリシーでは、拡張機能があなたのデータをどう扱うかを説明します。要点をまとめると、Submarine のサーバーは存在せず、拡張機能が開発者に何かを送ることはありません。

## ブラウザ内に残るもの

- 作成した、または開いた各保管庫の鍵と、その保管庫に付けた名前と色。これらはこのブラウザ専用の鍵で暗号化され、ロック用パスワードを設定すると、その鍵自体もロック用パスワードで保護されます。
- 保管庫の内容のコピー。ネットワークを待たずに保管庫を開けるようにするためのもので、これも暗号化されています。
- メールアドレスに届いたメッセージ。届いたときのまま、そのアドレスの鍵で暗号化されています。拡張機能は表示するたびにそれらを復号し、復号した状態で保存することはありません。
- 設定：ロックまでの時間、クリップボードを消去するまでの時間、パスワードジェネレーターのオプション、そして新しく作成するメールアドレスに使われるメールブリッジ、リレー、サーバー。
- 保存しないまま残したフォーム。拡張機能をもう一度開いたときに再表示するためのものです。ディスクには書き込まれずブラウザのメモリ上にだけ残り、保存、破棄、拡張機能のロック、ブラウザの終了のいずれかで消えます。

拡張機能から保管庫を削除すると、その鍵とコピーがブラウザから消去されます。拡張機能をアンインストールすると、拡張機能が保存したものはすべて消去されます。

## ブラウザの外に送られるもの

保管庫は Nostr のリレーに保存されます。リレーは独立した運営者が運営するサーバーで、誰のデータでも保存します。アイテムはリレーに届く前にデバイス上で暗号化されるため、リレーが保持するのは、リレー自身には読めないデータだけです。

保管庫をダウンロードするため、拡張機能はその保管庫のリレーに接続します。接続先は、各保管庫が指定しているリレー（指定がなければ Submarine の[デフォルトのリレー](https://github.com/nogringo/submarine/blob/main/packages/nostr_passwords/lib/src/defaults.dart)）と、保管庫のリレーリストが公開されている 3 つのディレクトリリレーです。各リレーには、ほかのウェブサイトを訪れたときと同じように IP アドレスが見えます。また、開いている各保管庫の公開鍵も見えます。拡張機能はこの公開鍵でリレーにログインし、その保管庫のデータを要求します。

アイテムを作成、編集、お気に入りに追加、ごみ箱に移動、または復元すると、拡張機能はその新しいバージョンをデバイス上で暗号化し、保管庫のリレーに送ります。アイテムを完全に削除すると、それらのリレーに各バージョンの削除を依頼します。まだどのリレーにも受け付けられていない変更は、ブラウザ内の暗号化されたコピーの中で待機し、次に拡張機能を開いたときか同期ボタンを押したときに再送されます。

パスワードジェネレーターはブラウザ内で動作します。生成したものがブラウザの外に出るのは、保存したアイテムに含まれている場合だけです。

Bitwarden のエクスポートファイルをインポートすると、拡張機能は選んだファイルをブラウザ内で読み込み、そこに含まれるアイテムを、あなたが作成したアイテムとして、選んだ保管庫に保存します。保管庫をエクスポートすると、拡張機能はファイルをパソコンに保存します。ファイルは選んだパスワードで暗号化されますが、パスワードでの保護をオフにすれば暗号化されません。ファイルがほかの場所に送られることはありません。

拡張機能のウィンドウやキーボードショートカットからログインの入力を指示すると、拡張機能は現在のページのログインフォームにユーザー名とパスワードを書き込みます。ただし、ページのアドレスがそのログインと一致する場合に限ります。ウェブサイトがそれらを受け取るのは、手で入力したときと同じく、ログインした時点です。

## メールアドレス

フィールドを追加するメニューから、ログインに `npub1...@uid.ovh` のような専用のメールアドレスを付けられます。拡張機能はアドレスごとに、保管庫とは無関係な新しい鍵を作成し、ログインの非表示フィールドに保存します。この鍵は、アイテムのほかの内容とともに暗号化されます。ドメインはメールブリッジのもので、設定でほかのものを選ばない限り `uid.ovh` です。メールブリッジは独立した運営者が運営するサーバーで、ほかのメールサーバーと同じようにそのアドレス宛てのメールを受け取り、アドレスの鍵で暗号化して、アドレスのリレーに渡します。拡張機能がメールを送ることはなく、ブリッジに接続することもありません。

新しいメールアドレスを付けたログインを保存すると、拡張機能は、ブリッジが配信先を知ることができるよう、アドレスの鍵で署名した 3 つの公開リストを公開します。アドレスのリレーのリスト（そのリレー自身と 3 つのディレクトリリレーに送られます）、メールが届くリレーのリスト、そしてリレーには大きすぎるメールを受け取るサーバーのリストです。これらのリストに載るのはアドレスの鍵とそのリレーやサーバーだけで、保管庫が載ることはありません。デフォルトでは、Submarine の[デフォルトのメール用リレーとサーバー](https://github.com/nogringo/submarine/blob/main/packages/nostr_passwords/lib/src/defaults.dart)が使われます。新しいアドレスに使うものは設定で変更できます。

メールアドレスのあるログインを表示している間、拡張機能は、ディレクトリリレーで見つけたそのアドレスのリレーに接続し、アドレスの鍵でリレーにログインして、最新のメッセージをダウンロードし、ログインを閉じるまで新しいメッセージを受信します。各リレーには、IP アドレスとアドレスの公開鍵が見えます。拡張機能は、その鍵宛てに送られたプライベートメッセージ（NIP-17）も受信します。リレーには大きすぎるメールは、開いたときに、暗号化されたままダウンロードされます。ダウンロード元は、アドレスまたはブリッジのサーバーのいずれか、それがなければ Submarine のデフォルトのサーバーで、そのサーバーには IP アドレスが見えます。

メールを保存すると、拡張機能は添付ファイルを含むメッセージ全体を、パソコン上のファイルに書き込みます。メッセージを削除すると、アドレスのリレーにその削除を依頼します。ログインを完全に削除しても、そのメッセージがリレーから削除されることはありません。メッセージ内のリンクは、拡張機能がリンク先を示し、あなたが確認した後でのみ、新しいタブで開きます。

## 拡張機能が行わないこと

- アカウントも独自のサーバーもありません。開発者が拡張機能からデータを受け取ることはありません。
- メールを送ることはありません。また、メールがウェブから読み込もうとする画像などのコンテンツを表示することもありません。メールはプレーンテキストとして表示します。
- 分析、トラッキング、広告は一切ありません。
- 訪れたページの内容は何も読み取りません。例外として、ログインの入力を指示したときは、ユーザー名とパスワードの入力先を見つけるために現在のページの入力欄を読み取ります。また、拡張機能を開いたときは、そのサイト用のログインを先頭に表示するために現在のタブのアドレスを読み取ります。どちらもブラウザの外には出ません。
- クリップボードに書き込むのは、あなたがコピーしたものと、入力したログインの認証コードだけです。その後、設定で選んだ時間が経つとクリップボードを空にします。クリップボードを読み取ることはありません。

## 権限

- ストレージ：上記のとおり、保管庫と設定をブラウザ内に保存します。
- クリップボードへの書き込み：指示に応じて、パスワード、コード、その他のフィールドをコピーします。
- アラーム：ロックまでの時間が過ぎたら保管庫をロックします。
- アクティブなタブ：拡張機能を開いたタブ、またはショートカットを使ったタブだけを拡張機能に渡します。そのアドレスは、そのサイト用のログインを先頭に表示するために使い、そのページは、指示に応じてログインを入力するために使います。
- スクリプト：指示に応じて、そのタブのページにログインを入力します。
- オフスクリーンドキュメント（Chrome のみ）：入力したログインの認証コードをコピーし、拡張機能のウィンドウを閉じていても、クリップボードを消去するまでの時間が過ぎたらクリップボードを空にします。
