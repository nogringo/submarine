# Submarine 浏览器扩展隐私政策

最后更新：2026年10月12日。

Submarine 是一款密码管理器。它的浏览器扩展会显示您密码库中的密码、支付卡和笔记，让您创建和编辑它们，帮您复制，并将您的登录信息填充到网站中。本政策说明扩展如何处理您的数据。简而言之：不存在 Submarine 服务器，扩展也不会向其开发者发送任何内容。

## 留在浏览器中的内容

- 您打开的每个密码库的密钥，以及您为它设置的名称和颜色。它们由此浏览器的一个密钥加密，而设置锁定密码后，这个密钥本身也受锁定密码保护。
- 密码库内容的副本，以便无需等待网络即可打开密码库。副本同样经过加密。
- 您的设置：自动锁定时间、剪贴板清除时间，以及密码生成器的选项。
- 您未保存就离开的表单，以便重新打开扩展时再次显示。它只保存在浏览器的内存中，绝不写入磁盘，并会在您保存、放弃、锁定扩展或关闭浏览器后消失。

从扩展中移除密码库，会从浏览器中删除它的密钥和副本。卸载扩展会删除它存储的所有内容。

## 离开浏览器的内容

您的密码库存放在 Nostr 中继上：这些服务器由独立的运营者运行，为任何人存储数据。您的项目在到达中继之前就已在您的设备上加密，因此中继只保存它们无法读取的数据。

为了下载您的密码库，扩展会连接到它们的中继：即每个密码库列出的中继（若没有则使用 Submarine 的[默认中继](https://github.com/nogringo/submarine/blob/main/packages/nostr_passwords/lib/src/defaults.dart)），以及发布密码库中继列表的三个目录中继。与您访问的任何网站一样，每个中继都能看到您的 IP 地址，还能看到您打开的每个密码库的公钥，扩展用这个公钥登录中继并请求该密码库的数据。

当您创建、编辑、收藏、移至回收站或恢复项目时，扩展会在您的设备上加密项目的新版本，并将其发送到所在密码库的中继。当您永久删除项目时，扩展会请求这些中继删除它的每个版本。尚未被任何中继接受的更改会留在浏览器的加密副本中等待，并在您下次打开扩展或点击同步按钮时重新发送。

密码生成器在您的浏览器中运行：它生成的内容只有放进您保存的项目中，才会离开浏览器。

当您通过扩展窗口或键盘快捷键要求填充登录信息时，扩展会将用户名和密码写入当前页面的登录表单，且仅在页面地址与该登录匹配时才会这样做。和您手动输入时一样，网站会在您登录时收到它们。

## 扩展不会做的事

- 它没有账户，也没有自己的服务器：开发者不会从它那里收到任何数据。
- 它没有数据分析，没有跟踪，也没有广告。
- 它不会读取您访问的页面的任何内容，唯一的例外是您要求填充登录信息时，它会读取当前页面的字段，以找到用户名和密码应填入的位置。在您打开扩展时，它会读取当前标签页的地址，以便优先显示该网站的登录信息。这两者都不会离开您的浏览器。
- 它只会把您复制的内容以及它所填充登录的验证码写入剪贴板，并在设置中选择的时间过后清空剪贴板。它从不读取剪贴板。

## 权限

- 存储：如上所述，将您的密码库和设置保存在浏览器中。
- 写入剪贴板：在您要求时复制密码、验证码或其他任何字段。
- 定时器：在自动锁定时间过后锁定密码库。
- 活动标签页：扩展只能访问您在其上打开扩展或使用快捷键的那个标签页，用它的地址优先显示该网站的登录信息，并在您要求时向它的页面填充登录信息。
- 脚本：在您要求时，将登录信息填充到该标签页的页面中。
- 离屏文档（仅限 Chrome）：复制所填充登录的验证码，并在剪贴板清除时间过后清空剪贴板，即使扩展窗口已关闭也是如此。
