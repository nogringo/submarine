# Bitwarden からパスワードをインポートする

Submarine は Bitwarden のエクスポートファイルを読み込めるので、パスワードの移行は数分で終わります。Bitwarden のアカウントには何の変更もありません。インポートはアイテムをコピーするだけです。

## 1. Bitwarden から保管庫をエクスポートする

1. Bitwarden のウェブ保管庫で「ツール」を開き、「保管庫のエクスポート」を選びます。Bitwarden のアプリでは、設定またはメニューに同じコマンドがあります。
2. .json 形式を選びます。好きなパスワードで保護された、暗号化 .json 形式を選ぶこともできます。Submarine はこちらも開けます。
3. Bitwarden のマスターパスワードを入力して確定し、ファイルを保存します。

Bitwarden アカウントに制限された暗号化エクスポートは使えません。開けるのは Bitwarden だけだからです。代わりに、パスワードで保護する種類を選んでください。

## 2. Submarine にファイルをインポートする

1. Submarine を開き、パスワードを入れる保管庫を作成するか、開きます。
2. **設定**、**インポートとエクスポート**の順に進み、**Bitwarden からインポート**の横にある**インポート**を押します。
3. ファイルを選びます。パスワードで保護されている場合は、そのパスワードを入力します。
4. 見つかったアイテムの数を確認し、保管庫が複数ある場合はインポート先の保管庫を選んで、**インポート**を押します。

アイテムはデバイス上で暗号化され、ほかの変更と同じように、ほかのデバイスに同期されます。

## 3. エクスポートファイルを削除する

パスワードなしの .json エクスポートは暗号化されていません。手に入れた人は誰でも、すべてのパスワードを読めてしまいます。インポートが終わったら削除し、パソコンのごみ箱も空にしてください。メールで送ってはいけません。

## インポートされるもの

- ログイン、カード、セキュアメモ、ID、SSH 鍵など、Bitwarden のすべての種類のアイテム。カスタムフィールドと 2 段階認証のコードも含まれます。
- ログイン、カード、セキュアメモは Submarine で編集できます。そのほかの種類も保存して表示しますが、まだ編集はできません。
- パスキーは保存して表示しますが、Submarine はまだパスキーでサインインできません。
- フォルダーはインポートされません。Submarine では、代わりに保管庫ごとにアイテムを分けます。
- 添付ファイルは Bitwarden のエクスポートに含まれないため、Bitwarden に残ります。

## ほかのパスワードマネージャーから移る場合

Submarine が読み込めるのは Bitwarden の形式だけです。Bitwarden 自体は、1Password、LastPass、KeePass、ブラウザなど、ほとんどのパスワードマネージャーからインポートできます。無料の Bitwarden アカウントを作って、まずそこにパスワードをインポートし、それから上の手順に従ってください。

## Submarine から移る場合

Submarine も同じ形式でエクスポートできます。**設定**、**インポートとエクスポート**の順に進み、**保管庫をエクスポート**を選ぶと、Bitwarden 形式のファイルが保存されます。ファイルはパスワードで保護するか、暗号化しないかを選べ、Bitwarden やほかのパスワードマネージャーでインポートできます。ごみ箱の中身は含まれません。

Submarine を初めて使う方は、[ダウンロード](/ja/download)するか、[Submarine がパスワードを守るしくみ](/ja/security)をお読みください。
