# 从 Bitwarden 导入您的密码

Submarine 能读取 Bitwarden 的导出文件，因此迁移密码只需几分钟。您的 Bitwarden 账户不会有任何变化：导入只是复制您的项目。

## 1. 从 Bitwarden 导出密码库

1. 在 Bitwarden 网页版密码库中，打开"工具"，然后选择"导出密码库"。Bitwarden 的各个应用在设置或菜单中也有同样的命令。
2. 选择 .json 格式。您也可以选择用自己设置的密码保护的加密 .json 格式：Submarine 同样能打开它。
3. 输入您的 Bitwarden 主密码进行确认，然后保存文件。

仅限您的 Bitwarden 账户使用的加密导出文件无法使用：只有 Bitwarden 能打开它。请改为选择密码保护类型。

## 2. 将文件导入 Submarine

1. 打开 Submarine，创建或打开要存放这些密码的密码库。
2. 依次进入**设置**、**导入与导出**，然后点击**从 Bitwarden 导入**旁边的**导入**。
3. 选择文件。如果文件受密码保护，请输入该密码。
4. 确认找到的项目数量，如果您有多个密码库，请选择目标密码库，然后点击**导入**。

您的项目会在您的设备上加密，然后像其他任何更改一样同步到您的其他设备。

## 3. 删除导出文件

没有密码的 .json 导出文件是未加密的：任何拿到它的人都能读取您的全部密码。导入完成后请删除它，并清空电脑的回收站。请勿通过电子邮件发送它。

## 导入的内容

- 登录、支付卡、安全笔记、身份、SSH 密钥以及 Bitwarden 的其他项目类型，连同它们的自定义字段和双重验证的验证码。
- 登录、支付卡和安全笔记可以在 Submarine 中编辑。其他类型会被保留并显示，但暂时还不能编辑。
- 通行密钥会被保留并显示，但 Submarine 暂时还不能用它们登录。
- 文件夹不会被导入：Submarine 改用密码库来区分项目。
- 附件不包含在 Bitwarden 的导出文件中，因此会留在 Bitwarden 里。

## 来自其他密码管理器

Submarine 只能读取 Bitwarden 的格式。Bitwarden 本身可以从大多数密码管理器导入，例如 1Password、LastPass、KeePass 或您的浏览器。使用免费的 Bitwarden 账户，先把密码导入到那里，然后按照上面的步骤操作。

## 离开 Submarine

Submarine 也以同样的格式导出。在**设置**、**导入与导出**中，**导出密码库**会保存一个 Bitwarden 文件，可以用密码保护，也可以不加密，Bitwarden 和其他密码管理器都能导入它。回收站中的项目不会被导出。
