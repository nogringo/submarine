# 运行您自己的服务器

Submarine 没有自己的服务器：默认情况下，您的密码库会复制到由独立运营者运行的公共 Nostr 中继上。添加您自己运行的服务器后，密码库的副本会一直保留在上面，保留多久由您决定。

## 您需要什么

- 一台可以从互联网访问的机器，例如租用的服务器或您家里的电脑。
- 一个指向这台机器的域名，并启用 HTTPS。
- Docker，用来安装下面的两个服务器。

## 1. 安装中继

按照 [nostr-relay](https://github.com/nogringo/nostr-relay) 的说明安装它。与大多数中继不同，它只把密码库的数据交给持有密码库密钥的人，并且允许您删除这些数据。

在它前面放一个转发原始 Host 请求头的 HTTPS 代理：中继需要这个请求头来确认 Submarine 持有密码库密钥。

它的地址以 `wss://` 开头，例如 `wss://relay.example.com`。

## 2. 安装文件服务器

附加到项目的文件保存在文件服务器上，而不是中继上。如果您也想自己保留一份这些文件，请按照 [blossom-server](https://github.com/hzrd149/blossom-server) 的说明安装它。

在它的配置文件中，把 `storage` 下的规则设为 `rules: []`。示例配置会删除一周内无人打开过的任何文件，您的附件也会因此被删除。

它的地址以 `https://` 开头，例如 `https://blossom.example.com`。

## 3. 把它们添加到密码库

1. 打开密码库设置，在**同步**下打开**中继**。
2. 点击**添加中继**，输入您的中继地址，打开**保持私密**，然后点击**添加**。
3. 点击**保存**。
4. 回到密码库设置，打开**文件服务器**，用同样的方式通过**添加服务器**添加您的文件服务器。

对您的每个密码库都这样做。**保持私密**会在密码库中加密这个地址：否则，任何人都能看到这个密码库保存在您的服务器上，并猜出它属于谁。

## 保留几个公共中继

在您自己的中继之外，保留几个公共中继：即使您的服务器停止运行或丢失数据，密码库仍然在它们上面。此外，您的每台设备也各自保留一份副本。
